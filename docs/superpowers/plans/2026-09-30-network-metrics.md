# Network Metrics and a Dashboard — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The operator exports player, group, server and heap metrics computed at scrape time, and the chart can ship a Grafana dashboard built on them.

**Architecture:** Agents add JVM heap to `PlayerCount`; the registry keeps it beside TPS/MSPT. A `NetworkCollector` in `internal/controller` (`prometheus.Collector`, registered in `metrics.Registry`) lists Networks, ServerGroups, Servers and proxy pods from the manager's cache on every scrape and reads the agent registry by pod UID. The dashboard JSON lives in the chart and renders into a ConfigMap behind `metrics.dashboard.enabled`.

**Tech Stack:** Go (client_golang, controller-runtime cache, testutil), protobuf, Kotlin agents, Helm, Grafana dashboard JSON (schema 39+).

**Spec:** `docs/superpowers/specs/2026-09-30-network-metrics-design.md`

## Global Constraints

- Dev shell for every command; envtest packages with `-p 1` on an 8-core machine.
- After proto/marker changes: `make proto manifests generate` (the metrics reference page is generated by `make manifests`).
- Metric names and labels exactly as the spec's table. Labels on per-server series: `namespace, network, group, server, node`; proxy: `namespace, network, group, proxy, node`; phase series add `phase`.
- Nothing stored between scrapes; a collect error on a list logs and emits what it has (never panics the scrape).
- `metrics.dashboard.enabled` defaults to false; rbacaudit's default-render object list stays unchanged.
- Conventional Commits, signed, session trailers; nothing consumer-specific.

## Review Focus

1. **A server with no report yet** — phase only, no zero-valued TPS/heap that would drag a "worst TPS" panel to 0. Pinned in Task 3.
2. **A deleted server** — its series vanish on the next scrape. Pinned in Task 3.
3. **An older agent (no heap)** — heap series absent, not 0. Pinned in Tasks 2 and 3.
4. **Dashboard drift** — a panel naming a metric that does not exist. Pinned in Task 4 (name cross-check).
5. **Scrape cost** — one List per kind per scrape from the cache, no API calls. Pinned by construction (collector takes a `client.Reader` that is the cache) and noted in the review.
